Portafolio profesional — Royber Calonge López
Sitio estático responsive en HTML, CSS y JavaScript, preparado para GitHub Pages.
Archivos
`index.html`: contenido y estructura.
`styles.css`: estilos adaptables a móvil, tableta y escritorio.
`script.js`: menú móvil, año automático y botón para copiar contacto.
`assets/`: retrato y marca de agua HGC.
Publicar con GitHub Pages
Crea un repositorio público en GitHub, por ejemplo `portafolio-royber`.
Sube todos los archivos y carpetas manteniendo esta estructura; `index.html` debe quedar en la raíz.
Abre Settings → Pages.
En Build and deployment, elige Deploy from a branch.
Selecciona `main` y `/ (root)`, luego pulsa Save.
Espera la publicación. GitHub mostrará la dirección pública en la misma sección Pages.
Antes de publicarlo
Revisa el contenido de experiencia y formación para confirmar que cada descripción refleja con precisión tus cargos y estudios. Los proyectos están etiquetados como personales/académicos y no se presentan como productos comerciales terminados.
